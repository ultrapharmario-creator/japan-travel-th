# Tabi • ญี่ปุ่นพร้อมเที่ยว

เว็บฝึกภาษาญี่ปุ่นสำหรับนักท่องเที่ยวไทย ฟรี ไม่ต้องสมัคร มีคำศัพท์และประโยค 139 รายการ 7 หมวด คำแปล คำอ่านไทย Romaji เสียง MP3 ประโยคโปรด แบบทดสอบ 10 ข้อ และเกมบทสนทนาร้านสะดวกซื้อ 12 ภารกิจ โดยเริ่มต้นที่หน้าฝึกคำศัพท์และประโยคจากภาพก่อนเล่นเกม

เกมเริ่มจากซื้อข้าวกล่อง อุ่นอาหาร ปฏิเสธถุง ขอตะเกียบ จ่ายด้วยบัตร และขอใบเสร็จ ต่อด้วยซื้อน้ำ รับถุง เลือกของใกล้พนักงานและของบนชั้นไกล ถามว่ารับบัตรไหม และขอให้พูดซ้ำ รวม 12 ด่าน คะแนนเต็ม 1,200 คะแนน สถิติของเกม 12 ด่านเก็บแยกจากเกมเดิม ผ่านครั้งแรกได้ 100 คะแนนต่อด่าน คำใบ้และคำตอบผิดลดครั้งละ 20 คะแนน คะแนนไม่ต่ำกว่า 0 และบันทึกสถิติสูงสุดในเบราว์เซอร์

## เปิดเว็บ
เปิด `index.html` หรือใช้เว็บเซิร์ฟเวอร์ static เช่น `python -m http.server 8080` แล้วเปิด http://localhost:8080

## GitHub Pages
อัปโหลดเฉพาะไฟล์ในโฟลเดอร์นี้ไปยัง repository สาธารณะ `japan-travel-th` แล้วเลือก Settings → Pages → Deploy from a branch → main → / (root) → Save

## iPhone และเสียง
ใช้ Safari แล้วแตะปุ่มฟังด้วยตนเอง เสียงใช้ไฟล์ MP3 ภาษาญี่ปุ่นที่เก็บในเว็บไซต์ ไม่ต้องติดตั้งเสียงญี่ปุ่นในเครื่อง มีตัวเล่นเสียงพร้อมปุ่มเล่น/หยุดและข้อความแจ้งเมื่อโหลดไม่ได้ หากเงียบให้ตรวจระดับเสียงและการเชื่อมต่อ Bluetooth สามารถ Share → Add to Home Screen เพื่อเปิดได้สะดวก คำอ่านไทยเป็นการประมาณเสียง ควรฝึกคู่กับเสียงญี่ปุ่น มี Romaji ครบทุกประโยค ค้นหาด้วยตัวอักษรโรมันได้ ใช้ ou/uu/ii เพื่อระบุสระยาว เช่น arigatou และ ku ukou (เขียนติดกันเป็น kuukou)

ประโยคโปรดและคะแนนเก็บใน localStorage ของเบราว์เซอร์ ไม่ส่งข้อมูลส่วนตัวไปยังเซิร์ฟเวอร์ หากปิดการบันทึกยังใช้คลังประโยคและแบบทดสอบได้ Google Fonts ต้องใช้อินเทอร์เน็ต และมีฟอนต์ระบบสำรอง

หมวดเฉพาะที่มี 6 ประโยคจะวนคำถามใหม่เพื่อครบ 10 ข้อ ตัวเลือกคำแปลดึงจากทุกหมวด เว็บนี้ไม่มีระบบหลังบ้านและไม่ต้องใช้ API key

## บทเรียนประกอบประโยคสำหรับมือใหม่
เลเวล 1 เริ่มจาก これ (kore), それ (sore), あれ (are) และ をください (o kudasai) ต่อด้วย お弁当 (obentou), この (kono), その (sono), あの (ano), คำถาม か (ka) และหัวข้อ は (wa) ทุกตัวอย่างญี่ปุ่นมี Romaji คำอ่านไทย และเสียง MP3 เก็บในเว็บไซต์

ในบทเรียนคำขอ เปรียบเทียบ お弁当をください (Obentou o kudasai) = ขอข้าวกล่อง, これをください (Kore o kudasai) = ขอสิ่งนี้ และ このお弁当をください (Kono obentou o kudasai) = ขอข้าวกล่องนี้ เพื่อให้เห็นว่าขอด้วยชื่อสิ่งของได้โดยไม่ต้องมีคำชี้เสมอไป

## เลเวล 2: เลือกอุ่นและเปลี่ยนใจ
ปุ่มเลือกระดับแยกเนื้อหาจากเลเวล 1 เรียนคำขอ 温めてください (Atatamete kudasai), คำขอไม่ให้ทำ 温めないでください (Atatamenaide kudasai), だけ (dake), やっぱり (yappari) และ こちら (kochira) ก่อนฝึกเปลี่ยนใจ เลือกอุ่นหนึ่งในสองกล่อง อุ่นเฉพาะหนึ่งในสามกล่อง และเว้นเฉพาะหนึ่งกล่องไม่ให้อุ่นพร้อมยืนยันว่าอีกสองกล่องให้อุ่น เสียงใหม่ IDs 122–134 ใช้ ja-JP-NanamiNeural เช่นเดียวกับเสียงเดิม

เลเวล 2 สอนรูป 他の (hoka no) + ชื่อสิ่งของหรือจำนวน เช่น 他の二つ (Hoka no futatsu) = อีกสองอัน, 他のお弁当 (Hoka no obentou) = ข้าวกล่องอื่น ๆ และ 他の飲み物 (Hoka no nomimono) = เครื่องดื่มอื่น ๆ มีเสียง IDs 135–138 โดยคำนี้ไม่บอกจำนวนเอง
