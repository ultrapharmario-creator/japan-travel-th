# Tabi • ญี่ปุ่นพร้อมเที่ยว

เว็บฝึกภาษาญี่ปุ่นสำหรับนักท่องเที่ยวไทย ฟรี ไม่ต้องสมัคร มี 48 ประโยค 7 หมวด คำแปล คำอ่านไทย Romaji เสียง MP3 ประโยคโปรด แบบทดสอบ 10 ข้อ และเกมบทสนทนาร้านสะดวกซื้อ 6 ภารกิจซึ่งเป็นหน้าหลักเริ่มต้น

เกมเริ่มจากซื้อข้าวกล่อง อุ่นอาหาร ปฏิเสธถุง ขอตะเกียบ จ่ายด้วยบัตร และขอใบเสร็จ ผ่านครั้งแรกได้ 100 คะแนนต่อด่าน คำใบ้และคำตอบผิดลดครั้งละ 20 คะแนน คะแนนไม่ต่ำกว่า 0 และบันทึกสถิติสูงสุดในเบราว์เซอร์

## เปิดเว็บ
เปิด `index.html` หรือใช้เว็บเซิร์ฟเวอร์ static เช่น `python -m http.server 8080` แล้วเปิด http://localhost:8080

## GitHub Pages
อัปโหลดเฉพาะไฟล์ในโฟลเดอร์นี้ไปยัง repository สาธารณะ `japan-travel-th` แล้วเลือก Settings → Pages → Deploy from a branch → main → / (root) → Save

## iPhone และเสียง
ใช้ Safari แล้วแตะปุ่มฟังด้วยตนเอง เสียงใช้ไฟล์ MP3 ภาษาญี่ปุ่นที่เก็บในเว็บไซต์ ไม่ต้องติดตั้งเสียงญี่ปุ่นในเครื่อง มีตัวเล่นเสียงพร้อมปุ่มเล่น/หยุดและข้อความแจ้งเมื่อโหลดไม่ได้ หากเงียบให้ตรวจระดับเสียงและการเชื่อมต่อ Bluetooth สามารถ Share → Add to Home Screen เพื่อเปิดได้สะดวก คำอ่านไทยเป็นการประมาณเสียง ควรฝึกคู่กับเสียงญี่ปุ่น มี Romaji ครบทุกประโยค ค้นหาด้วยตัวอักษรโรมันได้ ใช้ ou/uu/ii เพื่อระบุสระยาว เช่น arigatou และ ku ukou (เขียนติดกันเป็น kuukou)

ประโยคโปรดและคะแนนเก็บใน localStorage ของเบราว์เซอร์ ไม่ส่งข้อมูลส่วนตัวไปยังเซิร์ฟเวอร์ หากปิดการบันทึกยังใช้คลังประโยคและแบบทดสอบได้ Google Fonts ต้องใช้อินเทอร์เน็ต และมีฟอนต์ระบบสำรอง

หมวดเฉพาะที่มี 6 ประโยคจะวนคำถามใหม่เพื่อครบ 10 ข้อ ตัวเลือกคำแปลดึงจากทุกหมวด เว็บนี้ไม่มีระบบหลังบ้านและไม่ต้องใช้ API key
