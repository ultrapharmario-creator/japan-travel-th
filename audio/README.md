# Corrected warming pronunciation audio

The four files below were regenerated with pyopenjtalk 0.4.1, Open JTalk UTF-8 dictionary 1.11 and the bundled `mei_normal.htsvoice`, at speed 0.9, then encoded as mono MP3 at 128 kbps with FFmpeg. Hiragana explicitly fixes the intended pronunciation of 温めます as あたためます, rather than ぬくめます.

| File | Synthesis input |
| --- | --- |
| phrase-37.mp3 | お弁当をあたためますか |
| phrase-49.mp3 | かしこまりました。あたためます。 |
| phrase-67.mp3 | あたためます |
| phrase-91.mp3 | あたたかい |

The generated phoneme sequence for あたためます is `a t a t a m e m a s U` (the final U is devoiced). For あたたかい it is `a t a t a k a i`. The visible Japanese text retains the usual kanji spelling. Playback adds `?v=2` to these four files to invalidate cached versions.
